# LeetCode

C++ solutions, grouped by the technique used. Each file is named with the problem number and title and contains a `Solution` class. Some files note time and space complexity in a comment. The files have no `.cpp` extension.

| Folder | Problems | Examples |
| --- | --- | --- |
| `Array/` | 24 | Rotate Array, Shuffle the Array, Count Number of Bad Pairs |
| `LineSweeping/` | 7 | My Calendar I and II, The Skyline Problem, Car Pooling |
| `Graphs/` | 4 | Course Schedule, Clone Graph |
| `String/` | 3 | Reverse String II, Minimum Number of Swaps to Make the String Balanced |
| `stack/` | 3 | Minimum Add to Make Parentheses Valid, Maximum Width Ramp, Clear Digits |
| `Binary/` | 2 | Number of 1 Bits, Total Hamming Distance |
| `Adhoc/` | 2 | Integer Replacement, Count the Number of Consistent Strings |
| `Stack/` | 1 | Design a Stack With Increment Operation |
| repository root | 1 | 128. Longest Consecutive Sequence |

`stack/` and `Stack/` are both present. New stack problems should go in `stack/` so the folder name stays consistent.
